# 🎬 AI后期剪辑提成表生成工具

一键将 AI 项目分配表转换为完整的提成表，自动计算绩效、超额、缺集扣除和提成合计。

## ✨ 功能一览

| 功能 | 说明 |
|---|---|
| 📊 **自动解析** | 从项目分配表中提取人员、集数、交付日期 |
| 🧮 **智能计算** | 一卡/二卡/组长提成自动计算（基准70/120集） |
| 📄 **生成 Excel** | 完整提成表（格式与模板完全一致） |
| 📈 **统计简报** | Excel Sheet2 月度汇总 |
| 🌐 **可视化仪表盘** | 纯静态 HTML，含集数完成 & 提成排行 CSS 柱状图 |
| 🎨 **图形界面** | Tkinter GUI，无需命令行，无黑窗启动 |
| 👥 **角色管理器** | 可视化增删改人员角色 |
| 📂 **文件选择** | GUI 中自由选择项目文件与模板文件 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install pandas openpyxl
```

### 2. 启动

- 双击 **`启动工具.vbs`**（推荐，无黑窗）
- 或在终端运行：`python ai_commission_gui.py`

### 3. 使用

```
双击启动 → 检查文件 ✅ → 点击"角色配置"设置角色
→ 选择项目文件/模板 → 点击"一键生成"
→ Excel + HTML仪表盘自动打开
```

> 💡 本仓库已包含演示用的假数据（`一组AI项目.xlsx`、`config.json`），
> 你可以直接运行查看效果，然后替换为自己的数据。

## ⚙️ 角色与提成规则

通过 GUI 中的 **"⚙️ 角色配置"** 或在 `config.json` 中编辑：

```json
{
  "人员角色": {
    "王小明": "一卡剪辑",
    "李小红": "二卡剪辑",
    "张大星": "剪辑组长"
  }
}
```

### 角色标准

| 角色 | 基准集数 | 超额 | 缺集扣除 | 其他 |
|---|---|---|---|---|
| 🟢 一卡剪辑 | **70集/月** | +20元/集 | -50元/集 | — |
| 🔵 二卡剪辑 | **120集/月** | +20元/集 | -50元/集 | — |
| 🟣 剪辑助理 | **120集/月** | +20元/集 | -50元/集 | — |
| 🟠 剪辑组长 | **无限制** | — | — | 组内每部+100元 |

### 提成计算规则

- **一卡/二卡/助理**：超出基准 × 20元 = 提成；不足基准 × 50元 = 扣除
- **组长**：总集数 × 20元 + 全组去重项目数 × 100元

## 🔧 高级用法

### CLI 命令行

```bash
# 默认文件
python generate_commission.py

# 指定文件
python generate_commission.py 项目数据.xlsx 模板文件.xlsx
```

### 自定义规则

编辑 `config.json` 中的 `rules`，可修改基准集数、超额单价等。

### 从零开始

1. 复制 `config.example.json` → `config.json`
2. 在 GUI "角色配置"中添加人员
3. 放入自己的 `一组AI项目.xlsx` 和模板
