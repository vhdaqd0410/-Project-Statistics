# 🎬 AI后期剪辑提成表生成工具

一键将 AI 项目分配表转换为完整的提成表，自动计算绩效、超额、缺集扣除和提成合计。

## ✨ 功能

- 📊 **自动解析** 项目分配表，提取人员、集数、交付日期
- 🧮 **智能计算** 一卡/二卡/组长提成（规则可配）
- 📄 **生成 Excel** 完整提成表（格式与模板完全一致）
- 📈 **统计简报** Excel Sheet2 月度汇总
- 🌐 **可视化仪表盘** 纯静态 HTML（集数完成 & 提成排行柱状图）
- 🎨 **图形界面** Tkinter GUI，无黑窗启动
- 👥 **角色管理器** 可视化增删改人员角色

## 🚀 快速开始

### 1. 环境要求

```bash
pip install pandas openpyxl
```

### 2. 准备文件

| 文件 | 说明 |
|---|---|
| `一组AI项目.xlsx` | 项目人员分配数据 |
| `AI后期剪辑提成一组最新.xlsx` | 提成表模板 |
| `config.json` | 角色配置（复制 `config.example.json` 后修改） |

### 3. 运行

- **双击 `启动工具.vbs`**（推荐，无黑窗）
- 或在终端运行：`python ai_commission_gui.py`

## ⚙️ 配置说明

### 角色规则

编辑 `config.json`（或通过 GUI "角色配置"弹窗）：

```json
{
  "人员角色": {
    "张三": "一卡剪辑",
    "李四": "二卡剪辑",
    "王五": "剪辑组长"
  }
}
```

| 角色 | 基准集数 | 超额 | 缺集扣除 | 其他 |
|---|---|---|---|---|
| 一卡剪辑 | 70集/月 | +20元/集 | -50元/集 | — |
| 二卡剪辑 | 120集/月 | +20元/集 | -50元/集 | — |
| 剪辑助理 | 120集/月 | +20元/集 | -50元/集 | — |
| 剪辑组长 | 无限制 | — | — | 组内每部+100元 |
